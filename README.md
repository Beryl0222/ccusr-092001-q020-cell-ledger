# 跨物种细胞图谱实验账本

多个实验室把不同物种、组织、疾病状态的单细胞表达数据放进共同坐标空间时，
本服务负责记录完整谱系：数据集接入、物种与基因标识映射、质量检查、
训练/推理运行、嵌入版本、比较查询、研究者批注与后续验证，
让任何细胞相似性结论都能反向追溯输入、参数、代码版本与验证证据。

## 核心机制

- **事件溯源**：所有状态变化写入只追加的 JSONL 事件日志（默认 `ledger.jsonl`），
  重启重放恢复；审计记录永不删除。
- **受控词表**：数据许可、运行状态、证据等级以 `domain.json` 为单一事实来源。
- **许可守门**：受限数据（项目内使用 / 禁止再训练 / 限期使用）必须持有
  对应范围（训练/推理）的有效授权才能进入运行；被拒绝的尝试也记入审计。
- **撤销级联**：许可撤销后阻止新运行，把未完成运行、相关正式版本、
  依赖这些版本的结论标记为“已受影响”，历史记录保留供合规审计。
- **运行生命周期**：排队 → 运行中 →（失败可重试 | 正式版本）。
  失败重试沿用原运行身份；完成操作幂等，一次运行至多产出一个正式版本。
- **跨物种约束**：跨物种运行与查询必须显式声明基因映射与模型，
  且映射必须覆盖全部涉及物种、与版本训练时所用映射一致。
- **版本派生**：新数据到来时从既有版本派生新版本（`derived_from` 谱系），
  旧版本永不改写。
- **证据等级**：结论默认“模型推断”，验证记录只能把等级向更强方向推进。

## 快速开始

```bash
python3 service.py --check        # 校验配置与词表
python3 -m unittest -v            # 运行全部测试
python3 demo.py                   # 端到端演示（内存账本）
python3 service.py --port 8000    # 启动服务（持久化到 ledger.jsonl）
```

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/health` | 服务身份 |
| POST | `/datasets` | 注册数据集（物种/组织/疾病状态/许可） |
| PUT | `/datasets/<id>/qc` | 记录质量检查 |
| PUT | `/datasets/<id>/revoke` | 撤销许可（级联标记受影响产物） |
| GET | `/datasets/<id>/affected` | 撤销影响面报告 |
| POST | `/grants` / `/grants/revoke` | 签发 / 撤销数据使用授权 |
| POST | `/mappings` | 注册跨物种基因映射 |
| POST | `/models` | 注册模型（代码版本、参数） |
| POST | `/runs` | 提交训练/推理运行 |
| PUT | `/runs/<id>/start` `fail` `retry` `complete` | 运行生命周期 |
| POST | `/versions/<id>/derive`（PUT） | 从既有版本派生新运行 |
| POST | `/queries` | 比较查询（跨物种须显式映射与模型） |
| POST | `/conclusions` | 记录相似性结论 |
| GET | `/conclusions/<id>/trace` | 反向追溯输入/参数/代码版本/验证证据 |
| POST | `/annotations` | 研究者批注 |
| POST | `/validations` | 记录后续验证证据 |

错误以 JSON 返回：`400` 输入非法、`403` 许可拒绝、`404` 实体不存在、`409` 状态冲突。

## 文件

- `ledger_core.py` — 领域逻辑：账本、事件存储、许可与级联规则
- `service.py` — HTTP 服务层
- `domain.json` — 受控词表（许可 / 运行状态 / 证据等级）
- `demo.py` — 端到端演示
- `test_ledger_core.py` / `test_service.py` — 规则与接口测试
