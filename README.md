# 跨物种细胞图谱实验账本

多个实验室把不同物种、组织、疾病状态的单细胞数据放进共同坐标空间时，
样本命名、基因标识映射、数据许可与计算版本各不相同，一个有趣的细胞相似性
结论往往无法复现。本服务以**只追加事件账本**统一记录：

- 数据集接入（物种 / 组织 / 疾病、基因标识命名空间、样本命名规则、来源、校验和）
- 数据许可与项目级授权（可撤销，撤销后级联处置）
- 质量检查结论
- 跨物种基因标识映射（来源数据库版本、覆盖物种对、校验和）
- 代码版本与容器镜像摘要
- 训练 / 推理运行（参数、许可快照、尝试史）
- 模型版本与嵌入版本（谱系、晋升、受影响标记）
- 细胞相似性比较查询（**显式记录使用的映射与模型**）
- 研究者批注与后续验证（证据等级）

任何结论都可沿 `结论 → 查询 → 嵌入/模型版本 → 运行 → 输入数据集/质检/许可/代码`
完整反向追溯；新数据派生新版本，旧结果永不被改写。

## 快速开始

```bash
python3 service.py --check                 # 词表 + 审计哈希链自检
python3 service.py --port 8000             # 启动（默认持久化到 ledger.jsonl）
python3 -m unittest -v                     # 运行全部 30 个测试
curl http://127.0.0.1:8000/health
```

无第三方运行时依赖，仅需 Python ≥ 3.11（测试亦可用 `pytest`）。

## 核心设计

### 只追加事件 + 哈希链

所有状态变更都是不可变事件（`DatasetRegistered`、`AccessGranted`、
`RunStarted`、`VersionFlagged` …），事件含 `seq / ts / actor /
prev_hash / hash`，哈希对前一事件哈希与事件内容取 sha256。事件实时追加到
JSONL 审计文件；服务启动时重放重建状态并校验整条链——任何事件被篡改或
删除都会在 `--check` / 重放时抛出 `TAMPERED`。撤销、标记受影响只追加新
事件，**从不修改或删除历史记录**。

### 闸门（Gate）不变量

启动运行、重试、完成晋升、比较查询前统一校验：

1. **质检闸门**：无质检记录或「不通过」的数据集不能进入运行；
2. **许可闸门**：「禁止再训练」数据不得用于训练（推理允许）；「限期使用」
   到期失效；数据集级许可「已撤销」全局拒绝；
3. **授权闸门**：项目对每个数据集必须持有**当下有效**的授权；
4. **跨物种闸门**：覆盖多个物种时必须显式指定基因标识映射，映射必须覆盖
   全部相关物种对、未受影响；查询映射还必须与嵌入构建时的映射一致；
5. **版本闸门**：推理只能基于「正式版本」模型；「已受影响」嵌入不得查询。

失败聚合返回全部违规项，拒绝时账本不产生任何事件。

### 许可撤销的级联处置

`POST /grants/{id}/revoke` 在一条事务内追加事件并原子落盘：

- 授权置「已撤销」，此后新运行、重试、完成晋升、比较查询全部被阻止；
- 撤销时刻仍在排队 / 运行中且使用该数据的运行 → 「已受影响」，禁止晋升；
- 相关模型 / 嵌入版本 → 「已受影响」，并沿「模型 → 下游嵌入」谱系传递；
- 以该数据为依据的跨物种映射 → 「已受影响」；
- 授权事件、运行记录、版本谱系等全部审计证据原样保留。

### 失败重试与唯一正式版本

- 运行失败进入「失败可重试」，`retry` 在**同一 run_id** 下追加一次尝试，
  记录尝试史，不复制运行与谱系；
- 重试按当下时间重新执行全部闸门（许可可能在尝试间撤销 / 到期）；
- 完成运行时注册版本并晋升「正式版本」；重复完成回调是幂等的，
  **一个运行至多产生一个正式版本**，绝不出现两个。

### 版本派生与反向追溯

新数据到来时另开训练运行并以 `derived_from` 指向父模型：旧模型、旧嵌入与
旧结论全部保持不变。`GET /conclusions/{id}/trace` 返回完整证据图：
结论（含当前证据等级）、批注、验证、查询参数与映射、模型 / 嵌入版本链、
运行的代码版本与镜像摘要、参数校验和、许可快照、各输入数据集的质检与校验和。

证据等级按 `模型推断 → 计算复核 → 实验验证 → 同行确认` 只由**支持性**验证
提升；否定验证不提升，历史事件中初始等级不变。

## HTTP 接口

所有写操作为 `POST`，请求 / 响应均为 JSON；枚举字段必须取自 `domain.json`
词表。错误形如 `{"error": {"code", "message", "details"}}`，状态码：
400 参数/词表错误、403 许可或授权拒绝（`AUTH_DENIED`）、404 不存在、
409 冲突 / 状态不允许、422 映射不匹配。

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/projects` | 登记研究项目 |
| POST | `/datasets` | 接入数据集（许可、基因命名空间、校验和等） |
| POST | `/datasets/{id}/qc` | 记录质检结论 |
| POST | `/grants` | 项目对数据集授权 |
| POST | `/grants/{id}/revoke` | 撤销授权并级联标记 |
| POST | `/mappings` | 登记跨物种基因映射 |
| POST | `/code-versions` | 登记代码 / 镜像版本 |
| POST | `/runs` | 启动训练 / 推理运行（含全部闸门） |
| POST | `/runs/{id}/fail` | 标记失败可重试 |
| POST | `/runs/{id}/retry` | 安全重试（重新过闸门） |
| POST | `/runs/{id}/complete` | 完成并晋升唯一正式版本（幂等） |
| POST | `/queries` | 细胞相似性比较查询（跨物种须给 `mapping_id`） |
| POST | `/conclusions` | 记录相似性结论 / 假设 |
| POST | `/conclusions/{id}/annotations` | 研究者批注（只追加） |
| POST | `/conclusions/{id}/validations` | 追加验证证据 |
| GET | `/conclusions/{id}/trace` | **反向追溯完整证据图** |
| GET | `/datasets/{id}` `/runs/{id}` `/versions/{id}` | 实体视图 |
| GET | `/artifacts/affected` | 全部受影响产物（合规视图） |
| GET | `/events` | 原始审计事件链 |
| GET | `/state` | 当前物化状态 |
| GET | `/health` | 服务身份 |

### 最小端到端示例

```bash
curl -s localhost:8000/projects -d '{"project_id":"p1","name":"联合图谱"}'
curl -s localhost:8000/datasets -d '{"dataset_id":"d1","species":"人",
  "tissue":"外周血","disease":"健康","license":"开放研究",
  "gene_namespace":"HGNC","sample_naming":"labA_<donor>",
  "source_uri":"s3://h","checksum":"sha256:h"}'
curl -s localhost:8000/datasets/d1/qc -d '{"conclusion":"通过"}'
curl -s localhost:8000/grants -d '{"grant_id":"g1","dataset_id":"d1","project_id":"p1"}'
# …… 登记 code-version → 启动训练 → 完成 → 推理 → 查询 → 结论 ……
curl -s localhost:8000/conclusions/c1/trace
```

更完整的流程见 `test_service.py` 的 `seed_full_flow`。

## 文件结构

| 文件 | 职责 |
|---|---|
| `domain.json` | 领域词表（数据许可、运行状态 / 类型、证据等级、质检、产物状态） |
| `ledger.py` | 只追加账本：事件、哈希链、闸门、撤销级联、重试、追溯、重放 |
| `store.py` | JSONL 审计文件读写（追加 + fsync，顺序重放） |
| `service.py` | HTTP 服务、路由、错误码映射、`--check` 自检 |
| `test_ledger.py` | 22 个领域不变量测试 |
| `test_service.py` | 8 个端到端 HTTP / 持久化重启测试 |
